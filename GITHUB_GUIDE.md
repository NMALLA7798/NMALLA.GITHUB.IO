# Publish on GitHub Pages
1. github.com > **+** > **New repository**. Name it `YOUR-USERNAME.github.io` for the cleanest URL (or any name), set **Public**, create it.
2. **Add file > Upload files**. Drag in `index.html`, `pm.html`, `projects.html`, `.nojekyll` (if visible), `README.md` and the `src` folder. Click **Commit changes**.
3. **Settings > Pages**: Source **Deploy from a branch**, branch **main**, folder **/ (root)**, **Save**.
4. After 1 to 2 minutes the site is live at `https://YOUR-USERNAME.github.io/` (or `/REPO-NAME/`).
5. Put the link in your resume header and LinkedIn Featured section.

To add a photo: add `photo.jpg` to the repo and replace the `NM` badge in `index.html` with `<img src="photo.jpg" alt="Nischal Malla" width="116" height="116" style="border-radius:28px;object-fit:cover">`.
